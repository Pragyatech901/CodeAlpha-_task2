# CodeAlpha Task 2 – Stock Portfolio Tracker

## Project Overview
This project is a simple Stock Portfolio Tracker developed in Python as part of the CodeAlpha Python Programming Internship.

The program allows users to enter stock names and quantities and calculates the total value of their portfolio using predefined stock prices.

## Features
- Add stock names and quantities
- Store stock prices
- Calculate individual stock values
- Calculate total portfolio value
- Display portfolio details
- Simple console-based interface

## Technologies Used
- Python
- Dictionaries
- Loops
- Functions
- Conditional statements
- User input and output

## How to Run
1. Install Python.
2. Open the project folder in VS Code or PyCharm.
3. Run the Python file.
4. Enter the required stock and quantity information.

## Learning Outcome
This project helped me understand dictionaries, loops, functions, calculations, user input, and basic Python programming concepts.
